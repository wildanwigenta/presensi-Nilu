Face-api.js model files

Place the required face-api.js model files in this directory. Example models to download (from the face-api.js model repo):

- tiny_face_detector_model-weights_manifest.json and related binary files
- face_landmark_68_model-weights_manifest.json and related binary files
- face_recognition_model-weights_manifest.json and related binary files

After placing the files here, the frontend loader will fetch models from `/assets/models`.

Recommended source: https://github.com/justadudewhohacks/face-api.js/tree/master/weights
